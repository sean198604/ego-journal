# 2026-05-18 工作日志

## 项目学习

完成了 EGO Journal（众瀚四季）项目的全面学习理解：

### 项目定位
企业内部期刊展示平台，与文化积分系统（7006端口）同属企业文化生态

### 技术架构
- 前端：React 18 + Ant Design 5 + Vite（端口7007）
- 后端：FastAPI + SQLAlchemy（Docker内部8000，外部8002）
- 数据库：MySQL 8.0（端口3308）

### 核心模块
1. **期刊管理**：CRUD + 发布控制 + 外部链接跳转
2. **文章管理**：栏目分类 + 封面推荐 + 点赞功能
3. **用户权限**：admin/editor/reader 三级权限
4. **内容管理**：期刊简介/编辑部/征稿说明（当前存前端localStorage）

### 数据库设计
- users（用户）、journals（期刊）、categories（栏目）
- articles（文章）、likes（点赞）

### 启动方式
`docker-compose up -d --build`
