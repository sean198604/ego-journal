## 2026-05-19 下午 更新

### 内容管理后端迁移

**问题**：后台内容管理保存后不会返回到页面（因为用的是 localStorage，前台页面是硬编码内容）

**解决方案**：创建完整的后端内容管理 API

#### 后端实现
1. **新增数据库模型** `backend/models/models.py`:
   - `SiteConfig` 表：key-value 存储配置项
   - 字段：id, key(唯一索引), value(文本), label, description, group, updated_by, updated_at

2. **新增路由** `backend/routers/config.py`:
   - `GET /api/config` - 获取所有配置
   - `GET /api/config/group/{group}` - 按分组获取
   - `GET /api/config/public` - 公开配置（前台页面使用）
   - `PUT /api/config/{key}` - 更新单个配置
   - `POST /api/config/batch` - 批量更新配置
   - 初始化时自动创建默认配置（27项）

3. **前端 API** `frontend/src/services/api.js`:
   - 添加 `configApi` 对象

4. **前台页面**（3个页面全部从后端获取内容）:
   - `About.jsx` - 期刊简介页
   - `Editorial.jsx` - 编辑部介绍页
   - `Contribute.jsx` - 文稿征集页
   - 所有页面加载时调用 `/api/config/public` 获取配置

5. **后台管理** `AdminPage.jsx`:
   - ContentPanel 组件改为从后端加载配置
   - 保存时调用 `/api/config/batch` 批量更新
   - 移除 localStorage 相关代码
